# ✈️ Тревел-компромисс (Travel Compromise)

> Сервис для пар и друзей, который помогает найти идеальный город для совместного путешествия, учитывая пожелания, бюджет и вайб каждого участника.

---

## 🌟 Зачем нужен проект?
Собираетесь в отпуск с другом или второй половинкой, но спорите, куда поехать? Обычные поисковики не умеют совмещать разные точки отправления и разные предпочтения в один идеальный компромисс. 

**«Тревел-компромисс»** решает эту проблему:
* Каждый участник заполняет индивидуальные предпочтения (бюджет, даты, вайб, жесткие критерии) независимо друг от друга.
* Умный алгоритм сопоставляет данные и находит оптимальное направление.
* Сервис мгновенно подбирает транспорт с **отображением времени в пути** и предлагает прямые ссылки на покупку билетов и бронирование отелей через **Туту** для всех направлений.

---

## 🧭 Как пользоваться?

1. **Создайте путешествие:** Нажмите кнопку старта на сайте — система сгенерирует уникальные ссылки для вас и вашего напарника.
2. **Заполните форму:** Укажите город выезда, комфортный бюджет, даты поездки и желаемый «вайб» (движ, расслабон, природа, еда и т.д.).
3. **Получите результат:** Как только оба участника завершат ввод, приложение покажет город-победитель с процентом совпадения.
4. **Исследуйте альтернативы:** Если захотите изменить выбор, кликните на любую карточку альтернативного города в один клик, либо сразу переходите к покупке билетов.
